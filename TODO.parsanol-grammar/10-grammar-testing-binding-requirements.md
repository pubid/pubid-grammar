# 10 — Language-independent grammar, testing, and binding requirements

Everything that lives at the CONTRACT layer: the `.pg` sources, their
tests, and the capture/binding schemas that language models implement.

## Architecture principles

- **SSOT**: one grammar source per flavor; tests are single-sourced
  (inline `test` sections for rule-level expectations, `*.pgtest` suites
  for corpora; the artifact's embedded copy is derived and
  checksum-verified). The capture schema is *derived*, never authored.
- **OCP**: new lints, preprocess ops, and importers register into
  registries — the compiler core never grows a switch for a new rule
  kind.
- **SOTA**: tracked against XGrammar/llguidance (compiled grammar
  artifacts as interchange), 2025 PEG error-recovery research, and
  editor-grade DX (LSP).

## Tasks

- [ ] **F1 — flavor completion (medium).** Port cie, asme, oiml, astm,
      bipm with compile-time test blocks. ~1,500 parslet lines total.
- [ ] **F2 — flavor completion (giants).** ieee (1932 lines), ashrae,
      nist, itu, bsi. The bulk is stage/type/sponsor enumerations:
      extract them as gem-generated tables (`tables/<flavor>_*.yaml`,
      same pattern as iso/iec) and port the rule spines faithfully.
      Each carries a PN-5 test block from its own documented examples.
- [ ] **F3 — capture schemas as artifacts.** `schemas/<flavor>.schema.json`
      generated by `parsanol pg schema` in CI — the binding requirements
      (fields, types, cardinalities, preprocessing, example captures).
      This file is the CONTRACT the language-model implementers code
      against (see 12). Checksummed with the flavor.
- [ ] **F4 — corpora.** Per-flavor `corpora/<flavor>/`:
      (input, parsanol-tree, model-hash) triples generated from the Ruby
      reference. Suites iterate; corpora are the frozen cross-runtime
      conformance set. Define the promotion rule: a suite case that
      passes on the reference becomes a corpus case.
- [ ] **F5 — PG cross-file imports (`use`).** Today cen/idf spines are
      inlined (evs, iso joint). Design: `use cen_cenelec` imports rules
      namespaced (`cen.publisher`); cycles are compile errors; the
      artifact bakes the expansion so consumers never see imports.
      Unblocks de-duplicating shared lexicals and the joint grammars.
- [ ] **F6 — render/derive specs** (rs#144, G1). The to-string side:
      ordered segments + derive data in the artifact, generic renderer
      per language; graduation to an output grammar when 2+ flavors
      stabilize. Parse + render under one checksum = the full
      bidirectional SSOT.
- [ ] **F7 — structured parse error wire format** (rs#145, G2).
      `{offset, expected[], message}` flat wire on walker/VM/wasm/C ABI;
      Ruby cause trees remain the deep diagnostic; maps onto
      lutaml-model `error_types`.
- [ ] **F8 — parsanol-shape v2 freeze** (rs#146, G3): written contract +
      `shape` field verified at artifact load everywhere.
- [ ] **F9 — preprocessing vocabulary policy** (rs#147, G6): freeze or
      grow-with-minor after the flavor set stabilizes; ops stay
      registered strategies (data ops only — Tier 1).
- [ ] **F10 — self-hosting.** Parse PG with PG (the .pg grammar written
      in .pg, parsed by the compiled artifact). The end-user proof of
      the language; also the G7 import test bed.
- [ ] **F11 — PG LSP.** Diagnostics (lint + failing tests on save),
      hover (## doc comments), code action (reorder longest-first).
      SOTA authoring DX; built on the same compiler API.
- [ ] **F12 — specification completion.** PN 6: capture-schema format;
      PN 7: conformance protocol (corpora, promotion, pending ledger).
